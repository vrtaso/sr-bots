# Боты клана SILENT REQUIEM

В комплекте два независимых Telegram-бота:

- **anketa_bot.py** — приём анкет в клан (имя, возраст ≥13, скин-фото, уровень ≥40, часовой пояс), с кнопками «Принять/Отклонить» для модератора и историей всех анкет.
- **complaint_bot.py** — приём жалоб (текст + опциональное фото-доказательство), с историей всех жалоб.

Оба бота пересылают собранную информацию конкретному модератору личным сообщением и сохраняют историю обращений в JSON-файлы на диске (папка `data/`) — история переживает перезапуск бота.

## 1. Создание ботов в Telegram

1. Напишите **@BotFather** в Telegram.
2. Отправьте `/newbot`, задайте имя и username — повторите дважды (для каждого бота).
3. BotFather выдаст токен вида `123456789:AAExampleTokenXXXXXXXXXXXXXXXXXXXXX`. Сохраните оба токена.

## 2. Узнать chat_id модератора(ов)

Модератор должен написать любому боту-определителю id, например **@userinfobot**, и отправить `/start` — бот покажет его числовой `id`. Этот id и есть `MODERATOR_ID` / `MODERATOR_ID_COMPLAINTS`.

Если для анкет и жалоб модераторы разные — узнайте id для каждого отдельно. Можно указать и одного и того же человека в обоих полях.

> Важно: модератор должен **хотя бы раз написать своему** боту (anketa_bot / complaint_bot) `/start`. Это нужно по двум причинам: во-первых, у ботов нет права писать первыми пользователям, которые с ними не взаимодействовали; во-вторых, только после этого боту удастся настроить персональное меню команд с `/history` для него.

## 3. Запуск на Replit

1. Зайдите на **replit.com**, нажмите **Create App / Create Repl** и выберите шаблон **Python** (или импортируйте архив с этими файлами).
2. Загрузите все файлы проекта в Repl (перетащите в файловый менеджер слева).
3. Слева в панели инструментов откройте вкладку **Secrets** (значок замка 🔒) и добавьте переменные:

   | Key | Value |
   |---|---|
   | `BOT_TOKEN_ANKETA` | токен бота анкет от @BotFather |
   | `MODERATOR_ID` | chat_id модератора анкет |
   | `BOT_TOKEN_COMPLAINTS` | токен бота жалоб от @BotFather |
   | `MODERATOR_ID_COMPLAINTS` | chat_id модератора жалоб |
   | `CLAN_INVITE_LINK` | (необязательно) ссылка-приглашение в чат клана |

4. Нажмите **Run**. Replit сам поставит зависимости из `requirements.txt` и запустит `main.py`, который поднимает **оба** бота одновременно плюс небольшой веб-сервер (нужен, чтобы Repl не засыпал).
5. Напишите обоим ботам `/start` в Telegram (в том числе от лица модератора — это нужно, чтобы у него появилось персональное меню с `/history`).

### Чтобы боты работали 24/7

Бесплатный Repl засыпает после периода бездействия. Варианты:

- **Простой и бесплатный**: зарегистрируйтесь на [UptimeRobot](https://uptimerobot.com), добавьте HTTP-монитор с URL вашего Repl'а (он показывается сверху после запуска, вида `https://имя-репла.username.repl.co`) и интервалом проверки 5 минут.
- **Надёжный, платный**: включите в настройках Repl'а **Always On** / **Reserved VM**.

## 4. Локальный запуск (альтернатива, без Replit)

```bash
python3 -m venv venv
source venv/bin/activate        # на Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # затем впишите реальные значения в .env
python3 main.py                 # запустит оба бота сразу
```

Либо запускать ботов по отдельности (тоже подхватят .env):

```bash
python3 anketa_bot.py
python3 complaint_bot.py
```

Боты работают через long polling — процесс должен быть постоянно запущен, пока боты должны отвечать.

## 5. Как это работает

**Анкета (anketa_bot):**
1. Пользователь пишет `/start` — видит приветствие и кнопку **«📋 Оставить анкету»** внизу экрана (обычная reply-клавиатура, всегда под рукой).
2. Нажимает кнопку → бот последовательно спрашивает: имя → возраст → фото скина → уровень → часовой пояс.
3. В любой момент можно отменить заполнение командой `/cancel`, либо просто нажать кнопку «Оставить анкету» ещё раз — тогда анкета начнётся заново.
4. Если возраст < 13 или уровень < 40 — бот сообщает об отказе и не отправляет анкету модератору.
5. Если всё в порядке — готовая карточка анкеты (с фото скина) уходит модератору, под ней — кнопки **✅ Принять** / **❌ Отклонить**, и анкета сохраняется в историю со статусом «на рассмотрении».
6. Только тот, чей id указан в `MODERATOR_ID`, может нажимать эти кнопки (остальным бот покажет предупреждение).
7. После нажатия:
   - у модератора в сообщении дописывается статус, кнопки исчезают (повторно нажать нельзя);
   - статус анкеты в истории обновляется («принята» / «отклонена»);
   - заявителю приходит личное сообщение с решением (при одобрении — поздравление и, если задан `CLAN_INVITE_LINK`, ссылка на чат клана).

**Жалобы (complaint_bot):**
1. Пользователь пишет `/start` — видит приветствие и кнопку **«⚠️ Оставить жалобу»** внизу экрана.
2. Нажимает кнопку → бот просит описать жалобу текстом, затем приложить доказательства (фото/скриншот или «-», если их нет).
3. Отменить можно командой `/cancel` или повторным нажатием кнопки (жалоба начнётся заново).
4. Готовая жалоба уходит модератору (`MODERATOR_ID_COMPLAINTS`) и сохраняется в историю.

## 6. История обращений — команда /history

Оба бота хранят полную историю всех анкет/жалоб в JSON-файлах на диске (`data/anketa_history.json` и `data/complaints_history.json`) — она не теряется при перезапуске бота.

Команда **`/history`** показывает последние 20 записей (дата, кто, статус/текст) и работает **только у модератора**:
- в чате с любым другим пользователем эта команда отсутствует в списке автодополнения (`/`) — её просто не видно;
- если кто-то всё же наберёт `/history` вручную не будучи модератором — бот вежливо откажет («Эта команда доступна только модератору»).

Для анкет `/history` доступна пользователю с id из `MODERATOR_ID`, для жалоб — с id из `MODERATOR_ID_COMPLAINTS`.
