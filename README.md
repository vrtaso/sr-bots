# Боты клана SILENT REQUIEM

В комплекте два независимых Telegram-бота:

- **anketa_bot.py** — приём анкет в клан (имя, возраст ≥13, скин-фото, уровень ≥40, часовой пояс).
- **complaint_bot.py** — приём жалоб (текст + опциональное фото-доказательство).

Оба бота пересылают собранную информацию конкретному модератору личным сообщением.

## 1. Создание ботов в Telegram

1. Напишите **@BotFather** в Telegram.
2. Отправьте `/newbot`, задайте имя и username — повторите дважды (для каждого бота).
3. BotFather выдаст токен вида `123456789:AAExampleTokenXXXXXXXXXXXXXXXXXXXXX`. Сохраните оба токена.

## 2. Узнать chat_id модератора(ов)

Модератор должен написать любому боту-определителю id, например **@userinfobot**, и отправить `/start` — бот покажет его числовой `id`. Этот id и есть `MODERATOR_ID`.

Если для анкет и жалоб модераторы разные — узнайте id для каждого отдельно.

> Важно: модератор должен **хотя бы раз написать своему** боту (anketa_bot / complaint_bot) `/start`, иначе бот не сможет прислать ему сообщение (у Telegram-ботов нет права писать первыми пользователям, которые с ними не взаимодействовали).

## 3. Запуск на Replit (рекомендуемый способ)

1. Зайдите на **replit.com**, нажмите **Create Repl → Import from ZIP** (или "Upload folder") и загрузите архив `silent_requiem_bots.zip` целиком.
   - Либо: создайте пустой Python Repl и просто перетащите все файлы из архива в файловый менеджер слева.
2. Слева в панели инструментов откройте вкладку **Secrets** (значок замка 🔒) и добавьте 4 переменные:

   | Key | Value |
   |---|---|
   | `BOT_TOKEN_ANKETA` | токен бота анкет от @BotFather |
   | `MODERATOR_ID` | chat_id модератора анкет |
   | `BOT_TOKEN_COMPLAINTS` | токен бота жалоб от @BotFather |
   | `MODERATOR_ID_COMPLAINTS` | chat_id модератора жалоб |
   | `CLAN_CHAT_ID` | chat_id общего чата клана (см. ниже) |
   | `CLAN_INVITE_LINK` | (необязательно) ссылка-приглашение в чат клана |

   Можно указать одного и того же модератора в обоих полях, если анкеты и жалобы должен получать один человек.

   **Как узнать `CLAN_CHAT_ID`:** добавьте в общий чат клана бота @userinfobot (или @RawDataBot) — он пришлёт id чата, это будет отрицательное число вида `-1001234567890`. После этого бота-определитель можно удалить из чата. Обязательно добавьте туда и **anketa_bot** — он должен остаться в чате, чтобы присылать объявления.

3. Нажмите **Run**. Replit сам поставит зависимости из `requirements.txt` и запустит `main.py`, который поднимает **оба** бота одновременно плюс небольшой веб-сервер (нужен, чтобы Repl не засыпал).
4. Проверьте ботов в Telegram — напишите им `/start`.

### Чтобы боты работали 24/7

Бесплатный Repl засыпает после периода бездействия. Варианты:

- **Простой и бесплатный**: зарегистрируйтесь на [UptimeRobot](https://uptimerobot.com), добавьте HTTP-монитор с URL вашего Repl'а (он показывается сверху после запуска, вида `https://имя-репла.username.repl.co`) и интервалом проверки 5 минут — робот будет "будить" Repl.
- **Надёжный, платный**: включите в настройках Repl'а **Always On** / **Reserved VM** (платная функция Replit) — тогда пинговать не нужно.

## 4. Локальный запуск (альтернатива, без Replit)

```bash
python3 -m venv venv
source venv/bin/activate        # на Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # затем впишите реальные значения в .env
python3 main.py                 # запустит оба бота сразу
```

Либо запускать ботов по отдельности (тоже подхватят .env):

```bash
python3 anketa_bot.py
python3 complaint_bot.py
```

Боты работают через long polling — процесс должен быть постоянно запущен, пока боты должны отвечать.

## 6. Как это работает

**Анкета (anketa_bot):**
1. Пользователь пишет `/start` — видит приветствие и кнопку **«📋 Оставить анкету»** внизу экрана (обычная reply-клавиатура, всегда под рукой).
2. Нажимает кнопку → бот последовательно спрашивает: имя → возраст → фото скина → уровень → часовой пояс.
3. В любой момент можно отменить заполнение командой `/cancel`, либо просто нажать кнопку «Оставить анкету» ещё раз — тогда анкета начнётся заново.
4. Если возраст < 13 или уровень < 40 — бот сообщает об отказе и не отправляет анкету модератору.
5. Если всё в порядке — готовая карточка анкеты (с фото скина) уходит модератору, под ней — кнопки **✅ Принять** / **❌ Отклонить**.
6. Только тот, чей id указан в `MODERATOR_ID`, может нажимать эти кнопки (остальным бот покажет предупреждение).
7. После нажатия:
   - у модератора в сообщении дописывается статус, кнопки исчезают (повторно нажать нельзя);
   - заявителю приходит личное сообщение с решением (при одобрении — поздравление и, если задан `CLAN_INVITE_LINK`, ссылка на чат);
   - при **одобрении** в общий чат клана (`CLAN_CHAT_ID`) автоматически публикуется объявление о новом участнике (имя, уровень, часовой пояс).

   ⚠️ Список анкет, ожидающих решения, хранится в памяти процесса. Если бот перезапустится до того, как модератор нажал кнопку — по уже отправленной анкете кнопки перестанут работать (бот покажет уведомление «анкета недоступна»), нужно будет попросить подать анкету заново.

**Жалобы (complaint_bot):**
1. Пользователь пишет `/start` — видит приветствие и кнопку **«⚠️ Оставить жалобу»** внизу экрана.
2. Нажимает кнопку → бот просит описать жалобу текстом, затем приложить доказательства (фото/скриншот или «-», если их нет).
3. Отменить можно командой `/cancel` или повторным нажатием кнопки (жалоба начнётся заново).
4. Готовая жалоба уходит модератору (`MODERATOR_ID_COMPLAINTS`).
